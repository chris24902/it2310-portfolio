About Lab 2

In this lab, I learned how to use links, tables, and accessibility features to create more organized and user‑friendly web pages. I practiced working with relative and absolute links, which helped me understand how pages connect both within a site and to external resources. I also created HTML tables and learned how to structure them properly so information is clear and easy to read. Alongside this, I explored important accessibility attributes—such as using table headers, captions, and meaningful link text—to ensure that all users, including those using assistive technologies, can navigate and understand the content. Overall, this lab strengthened both my technical skills and my awareness of building accessible, well‑structured websites.
